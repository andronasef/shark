Create Sources/Shark/Services/UpdateChecker.swift as one file holding all update logic (locked design, one new file):

- `struct SemanticVersion: Comparable, Sendable` with stored `major, minor, patch: Int` and `prerelease: [String]`.
  - `init?(_ string: String)` trims whitespace and one leading "v" or "V", then drops everything from the first "+" (build metadata).
  - It splits at the first "-" into a core and a prerelease part. The core must be exactly three dot-separated non-negative integers. The prerelease part, when present, splits on "." into identifiers, and none may be empty. Anything else returns nil.
  - Equatable stays synthesized. Build metadata is not stored, so it is ignored.
  - `<` compares major, minor and patch numerically. A version with no prerelease ranks above one that has a prerelease. Two prerelease lists compare pairwise: both numeric compares as Int, numeric ranks below alphanumeric, and otherwise it is a plain String comparison. If every shared identifier is equal, the shorter list ranks lower.
  - Expose `var isPrerelease: Bool`.
- `struct GitHubRelease: Decodable, Sendable` with `tagName`, `draft`, `prerelease`, `htmlURL: URL` and `assets: [Asset]` (Asset has `name` and `browserDownloadURL: URL`). Use explicit CodingKeys for tag_name, html_url and browser_download_url so tests can decode with a plain JSONDecoder.
  - Add `var downloadURL: URL`: the first asset whose name hasSuffix(".dmg"), otherwise htmlURL.
- `enum InstallChannel: Sendable { case appStore, homebrew, dmg }`.
- `@MainActor enum UpdateChecker`. Mark the pure helpers `nonisolated static` so tests call them directly:
  - `channel(hasReceipt: Bool, hasCask: Bool) -> InstallChannel`. A receipt wins, then the cask, else dmg.
  - `newestRelease(in releases: [GitHubRelease], newerThan current: SemanticVersion) -> GitHubRelease?`. Skip drafts. Skip prereleases unless current.isPrerelease. Skip tags that do not parse. Return the release with the highest version only if it is greater than current.
  - `static var currentVersion: SemanticVersion?`, built from Bundle.main CFBundleShortVersionString.
  - `static func checkNow()` (manual). It starts `Task { await check(manual: true) }`.
  - `private static func check(manual: Bool) async`.
    - If currentVersion is nil and the check is manual, show an informational NSAlert: "Update checking is unavailable in development builds." (show the raw version string). If it is nil and automatic, return silently.
    - In this task, fetch GitHub only. Call `URLSession.shared.data(for:)` on https://api.github.com/repos/andronasef/shark/releases?per_page=10 with header Accept: application/vnd.github+json. Treat any non-200 HTTPURLResponse as an error. Decode `[GitHubRelease]` and call newestRelease.
    - On error: a manual check shows `NSAlert(error:)`, an automatic one stays silent.
    - When nothing is newer: a manual check shows "You're up to date" with informative "Shark Y is the newest version.", an automatic one stays silent.
    - When a release is newer, call `showUpdateAlert(latest:current:channel:actionURL:)`.
  - `private static func showUpdateAlert`:
    - NSAlert messageText "Shark \(latest) is available", informativeText "You have \(current)."
    - Buttons in order: the channel action button, "Skip This Version", "Later". In this task the only channel is dmg, whose button is "Download" and opens actionURL via NSWorkspace.
    - "Skip This Version" writes the latest version string to UserDefaults key "skippedUpdateVersion".
    - Before opening any network-derived URL, require url.scheme == "https" (threat T-x6a-01). Otherwise open https://github.com/andronasef/shark/releases.
  - Use the async URLSession API and keep all AppKit calls on the main actor (Swift 6 strict concurrency, no DispatchQueue).
- Sources/Shark/SharkApp.swift: in `HelpCommands.body`, add a second group, `CommandGroup(after: .appInfo) { Button("Check for Updates…") { UpdateChecker.checkNow() } }`. The ellipsis is the single character "…". This puts the item in the Shark app menu under About.
- Tests/SharkTests/UpdateCheckerTests.swift: write the tests in <behavior> first and watch them fail to compile or fail. Then implement until they pass. Decode release fixtures from inline JSON string literals with a plain JSONDecoder.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| api.github.com / itunes.apple.com → Shark | JSON from the network (versions, URLs) is untrusted input that drives alert text and the URL opened |
| Shark → NSPasteboard | the text the user will paste into Terminal |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-x6a-01 | Spoofing/Tampering | UpdateChecker.showUpdateAlert URL open | medium | mitigate | Open only https URLs, with a fallback to the hard-coded releases page; the App Store URL is only rewritten to macappstore. Requests use HTTPS under the default ATS. |
| T-x6a-02 | Tampering | Homebrew Copy Command | high | mitigate | The pasteboard gets the compile-time constant `brew upgrade --cask shark`; network text never reaches the pasteboard |
| T-x6a-03 | Denial of Service | JSON decode / non-200 / offline | low | mitigate | A typed Decodable rejects malformed data; errors are silent for automatic checks and shown as an alert for manual ones, and nothing crashes |
| T-x6a-04 | Information Disclosure | launch-time network request | low | accept | The request shows GitHub or Apple the client IP and that Shark is running, at most once a day; the user can turn it off in Settings › General |
| T-x6a-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this plan (locked: no new dependency) |
</threat_model>
