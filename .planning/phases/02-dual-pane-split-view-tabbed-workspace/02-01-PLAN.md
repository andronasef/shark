# Plan 02-01: Dual-Pane Split View & Tabbed Workspace

## Objective

Deliver KDE Dolphin's dual-pane split view (F3) and multi-tab workspace management in Shark. Enable side-by-side independent directory browsing, visual focus indication, keyboard-based pane switching (Tab), and robust tab lifecycle (Cmd+T, Cmd+W).

## Tasks

<task id="02-01-T1">
<title>Create WorkspaceTab and WorkspaceState Models</title>
<action>
Implement `PaneIdentifier` (`.primary`, `.secondary`).
Implement `WorkspaceTab` holding `primaryPane: NavigationState`, `secondaryPane: NavigationState`, `isSplit: Bool`, and `activePane: PaneIdentifier`.
Implement `@Observable` `WorkspaceState` holding `tabs: [WorkspaceTab]`, `activeTabID: UUID`, active navigation state accessor, and tab manipulation methods (`newTab()`, `closeTab(id:)`, `toggleSplit()`, `toggleActivePane()`).
</action>
<verify>
Models compile cleanly under Swift 6 strict concurrency.
</verify>
</task>

<task id="02-01-T2">
<title>Implement DualPaneContainerView and Active Focus Indicators</title>
<action>
Create `DualPaneContainerView` displaying the active tab's panes:
- Single pane when `!tab.isSplit`.
- Split view with customizable horizontal divider when `tab.isSplit`.
- Active pane visual indicator: accent border / outline / focus ring to clearly signal which pane has keyboard focus and drives the toolbar.
- Click-to-focus gesture on either pane.
</action>
<verify>
View renders both single and split modes properly with active focus styling.
</verify>
</task>

<task id="02-01-T3">
<title>Build TabBarView with Dynamic Titles and Shortcuts</title>
<action>
Create `TabBarView` displaying all open tabs with close buttons, plus button to add tabs, and dynamic titles reflecting the current folder name (e.g. "Documents" or "Documents | Downloads" in split view).
Support selecting tabs via click and keyboard shortcuts (Cmd+Shift+[, Cmd+Shift+]).
</action>
<verify>
Tab bar responds to tab creation, selection, and close actions.
</verify>
</task>

<task id="02-01-T4">
<title>Integrate into ContentView and Application Commands</title>
<action>
Update `ContentView` to use `WorkspaceState`, embedding `TabBarView` at the top of detail area and `DualPaneContainerView` below it.
Wire toolbar Split button (`F3`) and active pane routing for breadcrumbs, back/forward, and filter bar.
Add `F3` keyboard shortcut and `Tab` shortcut to cycle active split pane.
Connect `SharkApp` menu commands for New Tab (`Cmd+T`), Close Tab (`Cmd+W`), and Toggle Split (`F3`).
</action>
<verify>
`swift build` compiles the application cleanly without warnings.
</verify>
</task>
