# Plan 05-01: Information & Metadata Inspector (F11)

## Objective

Deliver KDE Dolphin's F11 Information & Metadata Inspector panel displaying high-resolution file previews, POSIX octal/symbolic permissions, owner/group info, MIME types, media dimensions, and on-demand SHA-256 checksums.

## Tasks

<task id="05-01-T1">
<title>Create FileMetadata Model and MetadataExtractor Actor</title>
<action>
Implement `FileMetadata` struct and `MetadataExtractor` actor providing asynchronous extraction of POSIX stat attributes (owner, group, octal mode), image dimensions via `CGImageSource`, media duration, and SHA-256 hashing via `CryptoKit`.
</action>
<verify>
Compiles under Swift 6 strict concurrency with zero data race warnings.
</verify>
</task>

<task id="05-01-T2">
<title>Build InspectorPanelView Component</title>
<action>
Implement `InspectorPanelView` in `Sources/Shark/Views/Inspector/InspectorPanelView.swift` displaying:

- General section (exact bytes, location path with copy button, created/modified dates)
- POSIX permissions section (octal mode e.g. 0644, symbolic -rw-r--r--, owner, group)
- Media section (dimensions for images/videos)
- Checksum section (SHA-256 calculation with copy button)
- Close button.
</action>
<verify>
Inspector component renders metadata cleanly in collapsible panel.

</task>
