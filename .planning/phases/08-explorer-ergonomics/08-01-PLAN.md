# Plan 08-01: Explorer Services & Operations

## Overview
Implement foundational services for Windows Explorer ergonomics:
1. `FileClipboardService`: Windows-style Cut / Copy / Paste clipboard with support for `.cut` and `.copy` operations, system pasteboard synchronization (`NSPasteboard`), visual state tracking (`isCut(url:)`), and clearing on cancel.
2. `FileUndoService`: Undo / Redo stack managing file system operations:
   - Moves (reverts by moving items back to source path)
   - Copies (reverts by deleting created items)
   - Renames (reverts by restoring old names)
   - Trash operations (reverts by moving back or re-creating)
3. `DiskSpaceService`: Reads available and total capacity on the target volume asynchronously using `URLResourceKey.volumeAvailableCapacityKey`.
4. `FolderSizeCalculator`: Computes folder size asynchronously with caching and thread-safe cancellation.
5. Unit tests for clipboard operations, undo/redo execution, and disk space calculation.
