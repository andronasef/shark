# Plan 08-02: Explorer UI, Controls & Verification

## Overview
Implement the visual surfaces and keyboard interactions for Explorer Ergonomics:
1. Cut/Copy/Paste wiring with `⌘X`, `⌘C`, `⌘V` and visual dimming (`opacity(0.45)`) on cut items.
2. Inline rename (Return key activates, stem selected, Esc cancels, Enter commits).
3. Rich Status Bar & Bottom Path Bar (Finder style, toggleable ⌥⌘P, items count, selection count + size, available disk space, background task progress indicator).
4. Forgiving Address Bar (⌘L / ⇧⌘G toggle, Tab autocomplete, error feedback).
5. Extended context menu actions (Open in Terminal, Compress/Archive, Copy Path variations, Open With).
6. Build, verify tests, and perform end-to-end GUI verification with `cua-driver`.
