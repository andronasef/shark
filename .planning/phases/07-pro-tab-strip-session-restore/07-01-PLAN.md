# Plan 07-01: Tab Strip State, Snapshot Model & Session Persistence

## Objective

Build the state and persistence foundation for Phase 7 (Pro Tab Strip & Session Restore):
1. Extend `WorkspaceTab` with pinned, locked, colour states, `Codable` `PaneIdentifier`, and tooltip formatting.
2. Create `WorkspaceSnapshot.swift` with pure value types for JSON serialization, lenient enum decoding, and `existingAncestor` path validation.
3. Extend `WorkspaceState` with full tab management operations maintaining the pinned-prefix and never-empty invariants, closed-tab history (capped at 20), tab jumping, folder open routing, snapshot creation, and restoration.
4. Implement `SessionStore.swift` with `withObservationTracking`, debounced autosaving, atomic writes, and safe crash-resilient restoration.
5. Provide comprehensive unit tests in `WorkspaceStateTests.swift` and new `SessionStoreTests.swift`.

<task id="07-01-T3">
<title>Extend WorkspaceState with Pro Tab Operations and Invariants</title>
<action>
Update `Sources/Shark/State/WorkspaceState.swift`:
1. Add `public var closedTabs: [ClosedTab] = []`
2. Add `@ObservationIgnored public var isTerminalVisible: Bool = false` for menu binding (Pitfall 1).
3. Update `newTab`:
   - Add parameter `placement: TabPlacement = .end` (`.end` or `.afterActive`), clamping the insertion index to `>= pinnedCount`.
   - Add optional `url: URL? = nil` and `select: Bool = true`.
4. Add `togglePin(id: UUID)`:
   - Pinning moves tab to `pinnedCount` (end of pinned group).
   - Unpinning moves tab to start of unpinned group.
   - Pinned-prefix invariant maintained.
5. Add `toggleLock(id: UUID)` toggling `isLocked`.
6. Add `setColor(_ color: TabColor?, for id: UUID)`.
7. Add `duplicateTab(id: UUID)`:
   - Clones panes, split state, view configuration, color, and pin state (lock state is NOT duplicated).
   - Inserts immediately after source tab (clamped to group). Selects new tab.
8. Update `closeTab(id: UUID)`:
   - Creates `ClosedTab` snapshot and prepends to `closedTabs`, capped at 20 entries.
   - If closing the last tab in the workspace, replace it with a fresh unpinned Home tab so tabs is never empty.
9. Add `closeOtherTabs(id: UUID)`:
   - Closes all tabs except `id`, preserving any pinned and locked tabs. Pushes closed tabs to `closedTabs`.
10. Add `closeTabsToRight(id: UUID)`:
    - Closes tabs to the right of `id` in the array, preserving pinned and locked tabs.
11. Add `reopenClosedTab(at index: Int = 0)`:
    - Pops closed tab from `closedTabs` (at given index, default 0).
    - Restores `WorkspaceTab`, inserts at `min(savedIndex, tabs.count)` clamped to pinned/unpinned invariant, and selects it.
12. Add `selectTab(number: Int)`:
    - 1-8 selects 0-indexed tab if in bounds; 9 selects the last tab.
13. Add `moveTab(id: UUID, to destinationIndex: Int)`:
    - Clamps movement within the tab's group (pinned tab stays within 0..<pinnedCount; unpinned stays within pinnedCount..<tabs.count).
14. Add `open(_ url: URL, from pane: NavigationState, newTab: Bool)`:
    - Find owning tab. If `newTab` is true (via ⌘ or middle click), open in a background tab inserted after current, keeping selection unchanged.
    - If owning tab is locked and `newTab` is false, open in a new foreground tab inserted after current.
    - Otherwise call `pane.navigateTo(url)`.
15. Add `snapshot() -> WorkspaceSnapshot` and `init(snapshot: WorkspaceSnapshot)`.
    - In `init(snapshot:)`: validate directories using `existingAncestor`, restore per-pane viewMode/sort/flags/iconSize, enforce pinned-prefix ordering, ensure `tabs` is not empty, clamp `closedTabs` to 20.
</action>

<title>Implement SessionStore Service with Debounce and Observation</title>
<action>
Create `Sources/Shark/State/SessionStore.swift`:
1. Use `os.Logger` for structured logging.
2. Provide initializer `init(fileURL: URL = URL.applicationSupportDirectory.appending(path: "Shark/session.json"))`.
3. Implement `restore() -> WorkspaceState?`:
   - Read data from `fileURL`. Return nil if file does not exist.
   - Decode `WorkspaceSnapshot` in `do/catch`. On decode error, log warning and return nil (fallback fresh, no crash).
   - Construct and return `WorkspaceState(snapshot:)`.
4. Implement `startAutosave(_ ws: WorkspaceState)`:
   - Use `withObservationTracking { _ = ws.snapshot() } onChange: { [weak self] in Task { @MainActor in self?.changed(ws) } }`.
5. Implement `changed(_ ws: WorkspaceState)`:
   - Re-arm `startAutosave(ws)`.
   - Cancel prior `saveTask`, create new `Task` with 500ms sleep, then `saveNow(ws)`.
6. Implement `saveNow(_ ws: WorkspaceState)`:
   - Cancel `saveTask`.
   - Create parent directory with `createDirectory(at:withIntermediateDirectories: true)`.
   - Encode `ws.snapshot()` and write using `.atomic` options.
</action>
