# Plan 10-01: Command Palette Engine & Modal Overlay

## Goal
Implement a high-performance, fuzzy-searchable Command Palette (⌘K / ⇧⌘P) that surfaces all actions, places, recent/frequent folders, tab groups, and typed paths.

## Tasks
1. Create `CommandPaletteService` / `CommandItem` model:
   - Command definitions with category, title, subtitle, icon, shortcut, and action closure.
   - Dynamic sources: application actions, standard places, recent folders, frequent folders, tab groups, and direct path navigation (`/` and `~`).
   - Fuzzy score matching with rank sorting.
2. Build `CommandPaletteView`:
   - Liquid Glass modal overlay over the main window.
   - Auto-focused search input, keyboard navigation (`↑`/`↓`), `Return` to trigger, `Esc` to dismiss.
   - Distinct categories and visual highlights.
3. Wire `⌘K` and `⇧⌘P` shortcuts and state in `WorkspaceState` and `SharkApp`.
4. Unit tests in `CommandPaletteTests.swift`.

## Deliverables
- `Sources/Shark/Services/CommandPaletteService.swift`
- `Sources/Shark/Views/Navigation/CommandPaletteView.swift`
- `Tests/SharkTests/CommandPaletteTests.swift`

## Verification
- Unit tests pass.
- Pressing ⌘K presents palette, typing filters commands, Return executes.
