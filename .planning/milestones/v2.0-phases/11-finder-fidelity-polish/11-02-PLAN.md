# Plan 11-02: Finder Fidelity, Liquid Glass & States (POL-01, POL-03, POL-04, POL-05, POL-06)

## Goal
Attain full visual parity with macOS Finder: liquid glass materials across backdrops, sidebars, and tab strips, polished empty/loading/permission-denied states with actionable guidance, full VoiceOver accessibility labels, Reduce Motion compliance, and a comprehensive `DESIGN.md`.

## Deliverables
1. **Liquid Glass & Translucent Vibrancy (POL-01, POL-06)**:
   - Ensure the main window background uses native vibrancy (`NSVisualEffectView` with `.behindWindow` blending mode and `.underWindowBackground` material).
   - Sidebar vibrancy using `.sidebar` material.
   - Unified toolbar and tab strip with translucent materials and subtle bottom divider.
   - Finder selection accent pill styling with crisp corner radius and contrast.
2. **States & Feedback (POL-03)**:
   - `DirectoryEmptyStateView`: Clean empty directory illustration, title, and shortcuts guide.
   - `DirectoryPermissionDeniedView`: Shield icon, clear permission explanation, and "Open Privacy Settings" button.
   - `DirectoryLoadingView`: Elegant progress indicator with fade-in.
   - Integrated into `DirectoryView.swift` whenever directory enumeration yields empty, loading, or permission errors.
3. **Accessibility & Reduce Motion (POL-04)**:
   - Ensure all interactive toolbar buttons, tabs, split buttons, and breadcrumbs have clear `.accessibilityLabel` and `.accessibilityHint`.
   - Add `@Environment(\.accessibilityReduceMotion) var reduceMotion` to transition animations to disable spring zooms if the user has requested reduced motion.
4. **DESIGN.md (POL-05)**:
   - Publish `DESIGN.md` in repository root documenting complete typography, color tokens, layout hierarchy, materials, component specs, keyboard bindings, and QTTabBar/Explorer feature parity.
5. **Unit Tests & Live Verification**:
   - Verify state view transitions and accessibility properties.
   - Test build and run with `cua-driver` verification.
