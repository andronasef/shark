# Plan 11-01: Real Miller Columns View (POL-02)

## Goal
Implement a real macOS Finder Miller Columns view (⌘3) featuring horizontally cascading directory columns, selected subdirectory expansion, terminal file preview pane with rich metadata, and intuitive arrow-key keyboard navigation.

## Deliverables
1. **`MillerColumnsCoordinator.swift`**:
   - Manages the column chain: `[ColumnState]` where each state holds `directoryURL`, `items: [FileItem]`, and `selectedItemURL: URL?`.
   - Dynamic loading: When an item is selected in column `i`, if it's a directory, column `i+1` is loaded; if it's a file, a preview pane is shown.
   - Arrow key navigation: `←` shifts focus to column `i-1`, `→` shifts focus to column `i+1`, `↑`/`↓` moves selection within the active column.
2. **`MillerColumnsView.swift`**:
   - Horizontal `ScrollView` with automatic scrolling to trailing column when new columns open.
   - Column width standard (240pt) with clean vertical dividers matching Finder.
   - Column items with folder disclosure chevron (`chevron.right`), icon, text, and native selection styling.
   - Terminal Preview Column:
     - Large file icon or Quick Look thumbnail.
     - Filename and file type.
     - Information table: Size, Created, Modified, Last Opened, Permissions.
     - Quick Look button (`Space`) and Open button (`⌘O`).
3. **Integration into `DirectoryView.swift`**:
   - Replace the placeholder `compactList` with `MillerColumnsView` for `ViewMode.compact`.
4. **Unit Tests**:
   - Column chain expansion and contraction.
   - Directory navigation via columns.
   - Preview selection of leaf files.
