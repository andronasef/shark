# Plan 10-02: Complete Menu Bar, Type-to-Select & Settings Window

## Goal
Deliver full keyboard navigation parity, menu bar completeness, type-to-select quick jump, and native Settings window.

## Tasks
1. Complete Menu Bar commands in `SharkApp.swift`:
   - File Menu: New Window (⌘N), New Folder (⇧⌘N), New File, Open (⌘O / ⌘↓), Get Info (⌘I), Quick Look (Space), Move to Trash (⌘⌫).
   - Edit Menu: Undo, Redo, Cut, Copy, Paste, Select All, Rename (Return / F2).
   - View Menu: Icon (⌘1), List (⌘2), Columns (⌘3), Gallery (⌘4), Toggle Split (F3 / ⌥⌘S), Toggle Terminal (F4 / ⌥⌘T), Toggle Inspector (F11 / ⌥⌘I), Toggle Path Bar (⌥⌘P), Toggle Status Bar, Show Hidden Files (⇧⌘.).
   - Go Menu: Back (⌘[ / ⌥←), Forward (⌘] / ⌥→), Enclosing Folder (⌘↑ / ⌥↑), Home (⇧⌘H), Desktop (⌥⌘D), Downloads (⌥⌘L), Documents (⌥⌘O), Go to Folder (⇧⌘G / ⌘L), Recents & Frequents.
   - Window & Settings: Settings (⌘,).
2. Type-to-Select:
   - Handle key strokes in `DirectoryView` / `DetailsTableView` / `IconsGridView`:
   - Rapid typing buffer accumulates characters, finds best matching item by prefix, selects it and scrolls into view.
   - Buffer resets after 800ms.
   - ⌘↓ opens selected folder/file; ⌘↑ navigates up.
3. Settings Window (⌘,):
   - `SettingsView` with tabs: General, Tabs, Previews.
   - Reactive settings using `@AppStorage`.
4. Unit tests and verification.
