## Objective

Deliver the complete user-facing Pro Tab Strip and system integrations for Phase 7:
1. Implement `MiddleClick.swift` hover registry and local NSEvent monitor.
2. Build `TabItemView.swift` and `TabStripView.swift` meeting all `07-UI-SPEC.md` styling and layout rules (28pt height, pinned 40pt icon-only tabs, unpinned 120-260pt tabs, hover close button, dot color, lock glyph, drag reorder, context menus). Delete legacy `TabBarView.swift`.

     - Center group: optional 8pt color dot, 14x14 folder icon, 11pt Regular middle-truncated title, optional 9pt `lock.fill` glyph.

   - Context Menu:
     - New Tab (`workspace.newTab(placement: .afterActive)`)
     - Duplicate Tab (`workspace.duplicateTab(id: tab.id)`)
     - Pin Tab / Unpin Tab (`workspace.togglePin(id: tab.id)`)
     - Lock Tab / Unlock Tab (`workspace.toggleLock(id: tab.id)`)
     - Colour submenu: None, Red, Orange, Yellow, Green, Blue, Purple, Gray (`workspace.setColor(...)`)
     - Divider
     - Copy Path (`NSPasteboard.general.clearContents(); NSPasteboard.general.setString(path, forType: .string)`)
     - Divider
     - Close Tab (`workspace.closeTab(id: tab.id)`)
     - Close Other Tabs (`workspace.closeOtherTabs(id: tab.id)`)
     - Close Tabs to the Right (`workspace.closeTabsToRight(id: tab.id)`)
     - Reopen Closed Tab (`workspace.reopenClosedTab()`, disabled if `workspace.closedTabs.isEmpty`)
   - Middle-click closing: `.onMiddleClick { workspace.closeTab(id: tab.id) }`.

     - `.onDrag` setting `$draggingID = tab.id`.

   - Trailing 28x28 "+" button: `Button { workspace.newTab(placement: .end) }` with 12pt semibold `plus` icon and `.help("New Tab (⌘T)")`.
   - Auto-scroll to active tab on change: `.onChange(of: workspace.activeTabID) { proxy.scrollTo(activeTabID) }`.
