# Plan 09-01: QTTabBar Folder Power Services & Data Engine

## Goal
Build the services and models that power QTTabBar folder operations:
1. `RecentFoldersService`: Record directory visits, calculate top frequent folders, keep last 30 recent folders, persist to JSON.
2. `TabGroupService`: Save current tabs snapshot as named tab groups, restore tab groups, persist to JSON.
3. `SubfolderMenuBuilder`: Build recursive `NSMenu` trees for arbitrary folder URLs with icons, navigation delegates, and modifier key actions.
4. `HoverPreviewService`: Extract thumbnails and head snippets for files with lightweight caching.
5. Unit tests validating all services.

## Deliverables
- `Sources/Shark/Services/RecentFoldersService.swift`
- `Sources/Shark/Services/TabGroupService.swift`
- `Sources/Shark/Services/SubfolderMenuBuilder.swift`
- `Sources/Shark/Services/HoverPreviewService.swift`
