# Plan 09-02: QTTabBar Folder Power UI & Verification

## Goal
Integrate the folder power services into the user interface:
1. Breadcrumb dropdown disclosure chevrons in `BreadcrumbBarView` and `BottomPathBarView` opening cascading native `NSMenu`s.

3. Hover preview popover in Details and Grid views (with configurable toggle).

6. Verification via `cua-driver`.
