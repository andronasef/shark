# Plan 06-01: File Operations Engine, FSEvents & Drag-and-Drop

## Objective

Deliver Dolphin's complete file operations engine (copy, move, duplicate, trash, delete, create folder/file, batch renaming), live macOS FSEvents monitoring for instant view updates, and native Drag-and-Drop between split panes, Finder, and sidebar.

## Tasks

<task id="06-01-T1">
<title>Implement FileOperationsService Actor</title>
<action>
Create `FileOperationsService` actor providing async methods for non-blocking file operations: copy, move, duplicate, trash, permanent delete, folder/file creation, and batch renaming (find/replace, prefix/suffix, sequential numbering).
</action>
<verify>
Compiles under Swift 6 strict concurrency with zero data race warnings.
</verify>
</task>

<task id="06-01-T2">
<title>Build FSEventsWatcher for Live File System Updates</title>
<action>
Implement `FSEventsWatcher` wrapping macOS `FSEventStream` with latency debounce, dispatch queue callback, and start/stop/watchURL methods that notify `NavigationState` to reload whenever external changes occur.
</action>
<verify>
FSEvents stream starts and stops cleanly on observed directory URLs.
</verify>
</task>

<task id="06-01-T3">
<title>Build BatchRenameSheet and NewItemSheet</title>
<action>
Create `BatchRenameSheet` showing live preview of new filenames with find-and-replace, prefix/suffix, and numbering rules.
Create `NewItemSheet` for creating folders (`⇧⌘N`) or new empty documents.
</action>
<verify>
Sheets render inputs and execute operations through `FileOperationsService`.
</verify>
</task>

<task id="06-01-T4">
<title>Integrate Drag-and-Drop and File Operations into UI</title>
<action>
Add `.draggable()` on directory items and `.dropDestination(for: URL.self)` on directory panes and sidebar items.
Connect context menus and keyboard shortcuts (`⇧⌘N` New Folder, `⇧⌘R` Batch Rename, `⌘⌫` Trash).
Connect `FSEventsWatcher` to `DirectoryView` to auto-reload on filesystem events.
</action>
<verify>
`swift build` compiles the application cleanly.
</verify>
</task>

<task id="06-01-T5">
<title>Unit Test FileOperationsService and Batch Renaming</title>
<action>
Create `Tests/SharkTests/FileOperationsTests.swift` testing folder creation, file duplication, batch renaming with pattern substitution, and file trashing.
Run `swift test`.
</action>
<verify>
All unit tests pass with 0 failures.
</verify>
</task>
