# Plan 04-01: Embedded Terminal Drawer (F4)

## Objective

Deliver KDE Dolphin's signature embedded terminal drawer (`F4`) powered by a native macOS pseudo-terminal (PTY) running the user's shell (`$SHELL`), with synchronized working directory tracking and an interactive terminal interface.

## Tasks

<task id="04-01-T1">
<title>Build PTYSession with POSIX openpty and Shell Spawn</title>
<action>
Implement `PTYSession` managing master/slave file descriptors via `openpty`, launching `$SHELL` (or `/bin/zsh`) in working directory, reading stdout/stderr asynchronously into an observable text buffer, and sending input data.
Support `syncDirectory(to:)` method sending `cd` commands when active pane changes.
</action>
<verify>
Compiles under Swift 6 strict concurrency and launches shell process.
</verify>
</task>

<task id="04-01-T2">
<title>Implement Native TerminalNSView and TerminalView</title>
<action>
Create `TerminalNSView` inheriting from `NSTextView` configured with dark terminal styling, monospace typography, disabled editing for output history, and key down interception that sends raw keystrokes to `PTYSession`.
Wrap in SwiftUI `TerminalView: NSViewRepresentable`.
</action>
<verify>
Terminal view renders shell output and transmits keystrokes to the PTY.
</verify>
</task>

<task id="04-01-T3">
<title>Create TerminalDrawerContainerView with Resizing Handle</title>
<action>
Build `TerminalDrawerContainerView` with collapsible bottom panel, top drag handle to adjust height (120pt to 500pt), header bar with working directory badge, "Clear" button, and "Close" button.
</action>
<verify>
Drawer smoothly collapses/expands and allows user resizing.
</verify>
</task>

<task id="04-01-T4">
<title>Integrate Terminal Drawer into ContentView and Toolbar</title>
<action>
Add terminal drawer toggle button in `ContentView` toolbar.
Add `F4` / `⌥⌘T` keyboard shortcuts.
Observe `workspaceState.activeNavigationState.currentURL` and forward changes to `PTYSession.syncDirectory(to:)`.
</action>
<verify>
`swift build` compiles the application cleanly.
</verify>
</task>

<task id="04-01-T5">
<title>Unit Test PTYSession Lifecycle and Directory Sync</title>
<action>
Create `Tests/SharkTests/TerminalTests.swift` testing PTYSession initialization, writing commands, shell execution, and directory synchronization logic.
Run `swift test`.
</action>
<verify>
All unit tests in `TerminalTests` pass with 0 failures.
</verify>
</task>
