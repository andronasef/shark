# Plan 01-01: Core Navigation & macOS Foundation

## Objective

Scaffold the native macOS Swift 6 application architecture, implement high-performance async file system listing, build the Places sidebar, interactive/editable breadcrumb bar, and single-pane directory browsing with full keyboard navigation.

## Tasks

<task id="01-01-T1">
<title>Initialize Swift Package and Project Scaffolding</title>
<action>
Create Package.swift configured for macOS 14+, Swift 6 language mode, with an executable target `Shark` and a test target `SharkTests`. Set up .gitignore for macOS/Xcode/SPM artifacts.
</action>
<verify>
`swift package describe` succeeds and validates the package manifest.
</verify>
</task>

<task id="01-01-T2">
<title>Implement FileItem Models and FileSystemService</title>
<action>
Build `FileItem` struct conforming to `Identifiable`, `Hashable`, `Sendable` holding attributes (url, name, isDirectory, isPackage, isHidden, isSymlink, fileSize, dateModified, kindDescription, systemIconName).
Build `FileSystemService` actor providing async directory contents loading using `FileManager.DirectoryEnumerator` or batch resource fetching for high performance, path expansion, and system volume discovery.
</action>
<verify>
Unit test checking async directory enumeration of system paths and attributes passes.
</verify>
</task>

<task id="01-01-T3">
<title>Build NavigationState and History Management</title>
<action>
Create `@Observable` `NavigationState` managing:
- Current working URL
- History stack (back/forward history arrays)
- Selected items
- Path editing state (for Cmd+L mode)
- Navigation actions: `goBack()`, `goForward()`, `goUp()`, `navigateTo(url:)`
</action>
<verify>
Unit test validating history push, pop, back, forward, and parent directory navigation.
</verify>
</task>

<task id="01-01-T4">
<title>Build PlacesSidebarView and BreadcrumbBarView</title>
<action>
Implement `PlacesSidebarView` using SwiftUI `List` with sections for Volumes, Places (Home, Desktop, Downloads, Documents), Favorites, and Trash.
Implement `BreadcrumbBarView` with clickable path segments for instant jump to parent folders, and direct text editing toggle (`Cmd+L`) supporting tilde expansion (`~`) and enter-to-navigate.
</action>
<verify>
Component builds and renders preview/view hierarchy properly.
</verify>
</task>

<task id="01-01-T5">
<title>Assemble DirectoryView, Main Window & Keyboard Shortcuts</title>
<action>
Implement `DirectoryView` displaying loaded `FileItem` elements with selection, double-click to open directory / open file, and empty state.
Assemble `ContentView` with `NavigationSplitView` hosting `PlacesSidebarView`, top toolbar with `BreadcrumbBarView`, Back/Forward/Up buttons, and keyboard commands (`Cmd+[`, `Cmd+]`, `Cmd+Up`, `Cmd+L`).
</action>
<verify>
`swift build` compiles the application cleanly without warnings or concurrency issues.
</verify>
</task>

<task id="01-01-T6">
<title>Create and Execute Test Suite</title>
<action>
Add tests in `SharkTests` verifying `FileSystemService` listing, volume enumeration, `NavigationState` history transitions, and path parsing. Run `swift test`.
</action>
<verify>
`swift test` exits with code 0 and all tests pass.
</verify>
</task>
