# Shark Notion Scope — Agreed Requirements

Source: [Scope Of Work](https://app.notion.com/p/andronasef/Scope-Of-Work-26286b1e0b02832eb34501783b1b26d4).
Planning interview: October 24, 2026. User accepted recommendations Q1–Q10 with “all you said is correct continue” and Q11–Q17 with “ok next.” Final plan review is pending; implementation has not been authorized by this document.

## Scope and order

Cover all eight open Notion items. Deliver moving correctness, terminal behavior, scrolling performance, and preview placement first; follow with toolbar/context menus, photo viewing, and complete app localization. Localization infrastructure may begin earlier, but translate final UI copy after the other features land. Verify the two Done items (updater and list double-click) as regressions.

## Agreed behavior

1. **Multi-file moves:** Dragging a selected item carries the selection; dragging an unselected item selects and carries only that item. Consistent supported selections across view modes and folder/background/sidebar/split destinations. Preserve same-volume move, cross-volume copy, Option-copy, Command-move, collision refusal, rollback, and Undo. Do not silently add column multiselect if unsupported.
2. **Terminal:** macOS Terminal is the reference for shell, keys, selection, and scrollback. Opening focuses it; clicking the directory restores file controls. Arrows, history, completion, Ctrl-C/D/Z, copy/paste, and interactive programs work without file shortcuts intervening. Cmd +/−/0 adjusts terminal text while focused, with remembered font size. Drawer is resizable. One persistent session per window; tab/pane navigation and hiding the drawer preserve the shell, command, and scrollback. Start in the active folder; subsequent directory changes require “Use Current Folder.” Preserve partly typed input and foreground programs. Restart/termination are explicit actions. No promise of session persistence across app quit.
3. **Performance:** Reproduce the 644-image icon-grid example from Notion and measure before changing architecture. Improve scrolling without losing previews or hover behavior; also verify large directory listing, sorting, filtering, and event refresh.
4. **Preview placement:** Fit the whole nonactivating panel inside the pointer's display usable bounds, including after asynchronous content sizing. Flip and shrink when needed, retain aspect ratio and reachable media controls, and preserve pointer handoff into the preview. Panel may extend outside the Shark window.
5. **Toolbar:** Native Customize Toolbar experience; add/remove/reorder built-in actions and coherent Navigation, Location, and View groups. App-wide saved layout, Restore Defaults, adaptive path width. No custom scripts/commands.
6. **Context menus:** Native, context-sensitive file/folder/multiselection/empty-space menus. Clear groups and labels, no internal QT identifiers. Add Open With and expose existing Share. Keep appropriate existing actions and Paste. Tag editing is separate; do not advertise the disabled placeholder as a feature.
7. **Photo viewer:** Dedicated window with explicit Open in Shark Photo Viewer action and optional image double-click setting; current default opening remains initially. Space stays Quick Look. Previous/next in filtered folder order; explicit selected-images-only mode. Thumbnail strip, zoom/pan, actual size, full screen, slideshow, metadata, view-only rotation. JPEG, PNG, HEIC, TIFF, animated GIF, and other system-decodable images; graceful unsupported/corrupt handling. Gallery gets actual previews. No image editing, RAW development, or comparison mode in this scope.
8. **Languages:** English, Arabic, Spanish, French, German, Brazilian Portuguese, Simplified Chinese, Japanese. Complete app UI, Help, settings, onboarding, menus and errors. System Default plus explicit override; restart acceptable. Correct Arabic layout and mixed-direction paths/filenames. Preserve stable persisted values. Website translation excluded.

## Delivery rules

- Native macOS file manager (Swift 6, SwiftUI with AppKit bridges, macOS 14+).
- Do not add a dependency for something a few lines of Swift or AppKit can do.
- Trash before deletion; never block the main thread on disk work.
- Meaningful logic gets tests; visible changes get running-app verification.
- Every feature/fix updates CHANGELOG.md and the website inventory; mouse bindings also update MouseHelp.zones; measurements/interactions update DESIGN.md.
- One feature or fix per conventional commit.

## Pre-implementation edge-case and UX review

These are acceptance refinements within the agreed scope, not additional headline features.

- **Dragging:** Freeze the payload at drag start; canceling a drag changes no files. Avoid including both a folder and its descendant as independent move sources. Preserve selected targets on right-click, resolve the clicked pane before executing actions, and never treat Favorites insertion/reordering as a file move. Reject self/descendant destinations through symlinks. Missing or inaccessible targets and volumes disconnected mid-operation must report failure without claiming full success. If rollback itself fails, report the actual remaining locations rather than hiding that failure.
- **Terminal:** Foreground shell ownership does not prove an empty prompt: read, heredocs, continuation prompts, pasted commands, and unfinished input all matter. No automatic Ctrl-U, Enter, cd, or control sequences. Use Current Folder must use a reliably identified safe prompt; otherwise offer to copy the quoted cd command, preserving all live input. Ctrl-C interrupts a process while Cmd-C copies selection. Scrolling back should not jump to bottom on every output update. Hiding must retain the process without keeping a visible/hittable ghost view; closing a window with a running child needs an explicit terminate decision. Natural shell exit must offer Restart rather than display an editable dead terminal. Shell cwd text must not falsely follow the browser or claim a cd succeeded.
- **Performance:** Reuse thumbnails only when file revision, requested pixel size, and display scale match. Deduplicate concurrent requests; cancellation of one consumer must not cancel another consumer's work. Bound decoded bytes as well as entry counts; large TIFFs and animated images can exceed a count-only cache. Prioritize visible content, release canceled work, and guard against stale completion after scrolling, folder changes, or refresh. Hover preview loading must also avoid synchronous image/text reads on the main actor.
- **Preview placement:** Cap content layout as well as panel geometry: shrinking only the outer window would clip controls. Maintain one stable anchor while content loads, ignore callbacks from superseded previews, and recompute for display removal/resizing or changed usable bounds. Preserve selection/focus and a reachable pointer path into the panel. Text can scroll when necessary; image aspect ratio remains intact. Respect reduced transparency/contrast.
- **Toolbar:** Removing a toolbar item must leave its command discoverable in menus/shortcuts. Very narrow windows use native overflow, not overlapping controls. Validate obsolete/duplicate saved IDs without discarding valid user choices. Reset only toolbar layout, not unrelated preferences. Keep sidebar toggle/traffic lights and native customization reachable. Test long translations before committing to fixed item widths.
- **Context menus:** Capture one target selection when the menu opens so its title, count, and executed action agree even if the folder refreshes. Right-clicking an unselected item acts on it; clicking an existing selection retains the batch. Show a shared Open With list for mixed file types only where an application can open all targets; otherwise explain/omit the inapplicable action. Canceling app/share pickers has no side effects. Folder terminal actions must name their target clearly and cannot silently retarget a busy terminal. Bulk Open must not unexpectedly launch hundreds of applications without an explicit bulk confirmation.
- **Photo viewer:** Retain the supplied filtered/sorted snapshot while browsing rather than jumping as folder contents change; missing files retain their place with a visible explanation and allow Next. At list ends disable Next/Previous; slideshow stops at the end. Zoom/pan/rotation reset for a different photo; fit-to-window recomputes on resize while actual size means one image pixel per display pixel, including Retina displays. Cancel old decodes and pause slideshow on errors, loss of active window, or interaction; respect Reduce Motion and stop animation when hidden. Do not load a whole folder at full resolution. Filename and index remain visible; Escape leaves full screen before closing the viewer. File modifications, orientation metadata, and corrupt images must not cause accidental writes or crashes.
- **Localization:** Never translate storage identifiers, shell commands, paths, extensions, user tab names, or application names supplied by macOS. Localize dynamic AppKit strings explicitly; preserve placeholders and plural counts across all languages. Mirror interface layout appropriately for Arabic while keeping terminal text and literal paths usable in their own direction. Mixed Arabic/Latin filenames, clipped labels, keyboard shortcuts on non-US layouts, fallback language, relaunch application, and packaged resources all get checks. Apply locale formatting only to display values, never machine-readable operations.

### Existing behavior clarified by source review

- Batch move rollback currently ignores recovery failures. Preserve the intent of all-or-nothing execution, but improve truthful partial-result reporting and recoverable Undo when the filesystem makes complete rollback impossible; do not claim a filesystem transaction exists.
- Existing drop behavior copies the whole batch when any source crosses volumes; Option takes precedence when both Option and Command are held. Retain these rules for this fix and make the offered operation accurate. Same-parent move is a no-op; Option-copy can create duplicates.
- Multi-folder Open should open distinct folder tabs rather than repeatedly navigating one pane and leaving only the final folder visible.
- Thumbnail failure fallbacks must be retryable; a transient access or decode error must not cache a generic icon permanently.
- Hover previews should preserve the whole image's aspect ratio rather than cropping extreme aspect ratios to a square. This deliberately replaces the current extreme-aspect cropping behavior.
