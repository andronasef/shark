All images are pre-existing assets supplied in this repository. No AI imagery or stock imagery is used.

| Shipping image | Origin | Transformation |
| --- | --- | --- |
| `src/assets/tabs-and-split.webp` | `docs/screenshots/tabs-and-split.png` | WebP quality 88, original dimensions |
| `src/assets/terminal.webp` | `docs/screenshots/terminal.png` | WebP quality 86, original dimensions |

| `src/assets/subfolder-menu.webp` | `docs/screenshots/subfolder-menu.png` | WebP quality 86, original dimensions |
| `public/icon.png` | `Resources/AppIcon.png` | Resized to 256 × 256 |

Astro generates responsive derivatives from the WebP originals at build time. UI icons are original inline SVG geometry in `src/components/Icon.astro`.
